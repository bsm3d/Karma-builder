A Karma render setup in one window

Camera, sky, lights, fog, clouds, materials, render variables and render settings: built in Solaris, then refined from the same window without losing what you did by hand.

What it builds

One button creates the same chain you would wire by hand. Run it again and it updates its own nodes: nodes you made yourself are never touched.

camera→sky or dome→fog→clouds→materials→AOVs→Karma settings→render ROP

What you get

Four lighting setups

Environment with a physical sky or an HDRI, Studio, 3 Points, and Interior with a window light and an optional view outside. Temperature and tint for every lamp.

Sky, fog and clouds

Karma physical sky with presets, volumetric atmosphere, fog, 3D or fast 2D clouds, and a wind or drift that moves them with the time.

Materials without MaterialX nodes

Sixteen basic materials, a general purpose PBR material with a texture set, random materials, and a simple editor for the everyday inputs.

Free material downloads

Browse ambientCG and Poly Haven, drag a material onto a prim of the list or onto an object of the Solaris viewport.

Live update

Move a slider and the render setup follows after a short pause. Changes that add or remove nodes wait for the Build button, so a running Karma viewport is not restarted for nothing.

Safe to run again

Only the nodes it created carry its tag. Yours are never deleted, rewired or moved, and the tool says so when a name is already taken.

Requirements

  • SideFX Houdini 21 or 22, with Solaris (LOPs) and Karma.
  • Nothing else to install: the interface only uses what ships with Houdini.
  • Install by unpacking a folder and double-clicking Install.bat (Windows), or with a package file (Linux, macOS). The guide has the steps.
